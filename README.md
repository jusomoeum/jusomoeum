## 🔎 레이더는 어떤 역할을 하나요?

### 분야별 사이트 탐색

무엇을 찾을지 막막할 때는 분야부터 선택해 보세요.

“유용한 사이트”처럼 넓게 검색하기보다 “문서 요약에 활용할 AI 도구”나 “지역별 채용정보”처럼 목적을 좁히면 비교할 대상을 정하기 쉬워집니다.

레이더는 관련 외부 웹사이트 정보를 카테고리별로 살펴볼 수 있도록 안내합니다.

### 서비스 정보 확인

사이트 이름만으로는 어떤 서비스를 제공하는지 알기 어려울 수 있습니다.

주요 기능과 이용 방법, 참고사항을 살펴보고 필요한 서비스인지 판단해 보세요. 실제 요금과 이용 조건은 해당 사이트에서 다시 확인하는 것이 좋습니다.

### 레이더 최신주소 안내

이전에 저장한 레이더 주소로 접속하기 어렵다면 주소 안내 페이지에서 현재 안내 중인 주소와 확인 날짜를 살펴보세요.

주소 안내는 이동 경로를 확인하기 위한 정보이며, 외부 서비스의 안전성이나 지속적인 운영을 보증하는 의미는 아닙니다.

## 🧭 레이더 링크모음 활용 방법

### 1. 필요한 작업을 한 문장으로 정하세요

찾고 싶은 사이트보다 먼저, 하려는 작업을 적어보세요.

- 긴 문서의 핵심 내용을 정리하고 싶어요.
- 관심 있는 분야의 질문과 경험을 찾아보고 싶어요.
- 원하는 지역의 채용공고를 비교하고 싶어요.
- 해외 쇼핑몰의 배송 조건을 알아보고 싶어요.

### 2. 목적에 맞는 카테고리를 선택하세요

필요한 분야를 먼저 선택한 뒤 관련 사이트를 살펴보세요.

처음부터 많은 사이트를 저장하기보다 비교할 후보를 몇 개로 좁혀보는 것도 방법입니다.

### 3. 같은 기준으로 비교하세요

후보마다 다음 항목을 확인해 보세요.

- **기능:** 내가 하려는 작업을 지원하나요?
- **이용 조건:** 가입이나 결제가 필요한가요?
- **언어:** 서비스 안내를 이해할 수 있나요?
- **정보 시점:** 공지사항이나 자료가 언제 작성되었나요?
- **개인정보:** 어떤 정보를 입력하거나 제공해야 하나요?

### 4. 공식 사이트에서 최종 확인하세요

서비스 범위, 요금, 운영정책은 변경될 수 있습니다.

레이더의 안내를 참고해 후보를 찾고, 실제 이용 전에는 해당 사이트의 최신 내용을 직접 확인해 주세요.
